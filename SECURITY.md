# Segurança

## Como relatar uma falha

Use o aviso de segurança privado do GitHub deste repositório (aba *Security*, botão
*Report a vulnerability*). Não abra uma issue pública e não envie detalhes por outro canal.

Inclua: o que acontece, como reproduzir e o que você viu de efeito. Responderemos no próprio
aviso.

## Escopo

O projeto guarda anotações privadas de estudantes. Qualquer forma de ler a anotação de outra
pessoa, entrar sem convite ou contornar o segundo fator da administração é tratada como grave.
